# HARAKA Elevate

HARAKA Website - Master Prompt for Lovable AI

PROJECT OVERVIEW

Build a world-class, enterprise-grade corporate website for HARAKA Strategic Partners Ltd, a premium Business Consulting, Technology Solutions, AI, and Project Delivery company headquartered in Rwanda and serving clients across East Africa.

The website must position HARAKA as a trusted partner for governments, NGOs, SMEs, large enterprises, and international organizations. It should communicate professionalism, innovation, credibility, and technical excellence from the first interaction.

This website is not a startup landing page. It should look and feel like the websites of Accenture, IBM Consulting, Deloitte Digital, McKinsey, and BCG X while maintaining HARAKA's own unique identity.

The experience should be premium, modern, fast, elegant, highly interactive, and conversion-focused.

The website should clearly communicate HARAKA's purpose, expertise, services, technology capabilities, products, industries served, leadership, and contact information, encouraging visitors to book consultations and begin long-term partnerships. The company profile should be the primary source of content.
